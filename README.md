# Lift Log

Personal gym app: weekly plan, set-by-set logging with last time's weights, body parts covered each week,
body weight and measurements, and YouTube trainer videos stamped at each exercise (Beginner / Intermediate / Advanced).

Live: https://sagarchakraborty-creator.github.io/lift-log/

Data stays on the phone (localStorage). Settings → Save backup to keep a copy.

Update: edit, bump `VERSION` in `sw.js`, commit, push.
